# MyPortfolio

A local FastAPI implementation of Jaskirat Singh Narang's portfolio.

## Run locally

```powershell
cd MyPortfolio
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app:app --reload
```

Open http://127.0.0.1:8000.

## Stack

- FastAPI for the Python web application
- Jinja2 for server-rendered HTML
- CSS for the responsive visual system
- A small progressive-enhancement JavaScript file for reveal animation

The existing ChatGPT Site is independent and remains deployed.
